# Cat螢幕轉換器 1.0.0 · QxQ

提供貓專用的近似色差顯示，讓值班畫面更好分辨。

## 安裝與啟動

1. 下載 `QxQ-CatScreenConverter-Setup-1.0.0-win-x64.exe`。
2. 執行安裝程式，可選擇建立桌面捷徑。
3. 安裝完成後直接啟動，或從開始功能表開啟「Cat螢幕轉換器」。

適用 Windows 10 22H2／Windows 11 的 x64 電腦。安裝於目前使用者帳號，已包含 .NET 執行元件，無需另外安裝 .NET。

## 功能

- 「正常／貓」一鍵切換全桌面色彩。
- 調整貓用色差強度、工作畫面亮度與明暗對比。
- 視窗內容隨大小等比例縮放。
- `Ctrl + Alt + N` 交回人類值班，還原原本色彩。
- 正常關閉時還原色彩；從 Windows「已安裝的應用程式」可解除安裝。

這是近似的色差轉換，並非經過貓咪行為實驗驗證的色覺校正。HDR、多螢幕及獨佔全螢幕相容性尚待確認。

安裝檔目前未使用發行者憑證簽署。若 Windows 顯示來源提醒，請核對下載來源與 `SHA256SUMS.txt`。
